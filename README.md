# StudyFind

StudyFind is a student-focused academic resource and study-guide website.

## Project report
Open [report.html](report.html) in a browser. Select **Edit report text** to customise student details, then use **Print / Save as PDF** to export the report.

## Project links
- Hatchable app: https://studyfind.hatchable.site
- Hatchable console: https://hatchable.com/console/projects/studyfind

## Notes
The report is an editable template. Replace placeholders, verify the described features against the deployed build, and enter real test results before academic submission.
